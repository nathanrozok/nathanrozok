A TensorFlow/Keras image-classification project comparing a baseline convolutional neural network with an optimized model designed to improve generalization.

- Diagnosed significant overfitting in the baseline model
- Applied architectural and training changes including reduced dense layers, dropout, and early stopping
- Improved validation accuracy from approximately 91% to 94%
- Documented the experiment, tradeoffs, and results
